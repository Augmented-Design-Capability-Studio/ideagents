description), and a list of axes (with id, name, direction: whether higher

where each concept actually falls on that raw axis; direction is used
separately to interpret it. Add a one-sentence justification per estimate.
These are rough, low-confidence estimates for a pilot study — say so
implicitly by keeping justifications short and hedged, not authoritative.

Respond with ONLY JSON (no prose, no markdown fence):
{
  "estimates": [
    { "conceptId": string, "axisId": string, "low": number, "likely": number, "high": number, "justification": string },
    ...
  ]
}
Include one entry for every concept x axis combination given.
